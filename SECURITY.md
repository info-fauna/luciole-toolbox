# Security Policy

## Supported Versions

Only the latest published release on [PyPI](https://pypi.org/project/luciole-toolbox/)
is supported with security fixes.

## Reporting a Vulnerability

Please report security issues privately by emailing
support@infofauna.ch rather than opening a public issue. Include steps
to reproduce and the impact if known. We'll acknowledge the report and
aim to follow up with a fix or mitigation timeline.
